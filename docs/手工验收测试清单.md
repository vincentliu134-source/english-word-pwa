# 手工验收测试清单

## 测试准备

- 使用 Chrome 或 Edge 打开 `enhanced-word-tool.html`
- 首次测试前，建议清空当前页面的 `localStorage`
- 准备一个符合格式的 Excel 文件，或直接使用页面下载模板

## 1. 首页与基础配置

- 打开页面后，确认首页正常显示
- 确认默认年级和难度已自动选中，不应出现空白状态
- 调整“单词数量”滑块，确认数字同步变化
- 调整“学习时间”滑块，确认分钟数同步变化
- 点击“重置为默认”，确认恢复为 `10 个单词 / 5 分钟`

预期结果：

- 页面无报错
- 控件联动正常

## 2. 卡片学习

- 点击“卡片学习”
- 确认能够进入卡片页面
- 确认图片、中英文、单词发音和例句在一屏内展示
- 点击「帮我记一记」，确认只显示该词适用的提示
- 检查 `taste`，不应出现 `tas-te`；检查 `airport`，应可显示 `air + port`
- 点击「我记住了，开始挑战」，确认直接进入主动回忆
- 点击喇叭按钮，确认触发浏览器发音
- 点击“下一个”，确认能切换单词
- 完成单词后，确认总结页不自动跳转，需手动点「确认下一张」
- 点击“上一个”，确认第一页时按钮不可用，其他页可回退
- 返回已学词后再向前切换，确认无需重学；未学词仍不能越过

预期结果：

- 卡片页面可正常浏览
- 无空白卡片

## 3. 主动回忆挑战

- 在首页点击“开始游戏”
- 确认进入主动回忆挑战页面
- 输入正确答案，确认提示为正确并自动进入下一题
- 输入错误答案，确认提示正确答案且不会直接跳题
- 连续点击提示按钮，确认最多 3 次
- 使用提示后答对，确认得分会受到影响
- 点击右上角发音按钮，确认可以读当前英文词
- 等待时间结束，确认自动进入结果页

预期结果：

- 正确/错误反馈清晰
- 进度条、分数、倒计时正常更新
- 本轮有错词时，确认自动生成「薄弱点小回合」

## 4. 今日单词小故事

- 先完成至少 2 个单词，返回首页点「今日单词小故事」
- 确认生成 2～5 个目标词、一篇短文和 3 道题
- 点目标词，确认显示中文并朗读；测试整篇与逐句朗读
- 故意答错一题，确认该词进入薄弱点复习

预期结果：

- 阅读页桌面端两列、手机端单列，无水平溢出
- 题目进度和答对数实时更新

## 5. 学习记录与分析

- 完成至少 1 局游戏
- 进入“数据分析”页面
- 确认总学习次数增加
- 确认累计学习单词数与本轮实际题量一致
- 确认最近学习记录能显示本次年级、难度、正确率、首次答错数、用时
- 故意做错若干题后再查看，确认“首次答错单词”和“高频错误单词”有对应内容

预期结果：

- 统计数据与实际作答基本一致

## 6. Excel 单词库导入

- 打开“单词库管理”
- 点击“下载Excel模板文件”
- 上传一个符合模板格式的 Excel 文件
- 确认页面提示导入成功，并显示年级分布
- 返回首页，选择对应年级和难度开始学习
- 确认展示的是导入后的词
- 点击“使用默认单词库”，确认可切回默认词库

预期结果：

- 自定义词库可导入、可切换、可使用

## 7. 图片自定义

- 先进入卡片学习
- 点击左上角铅笔按钮
- 输入图片 URL 并保存
- 返回卡片，确认图片更新
- 再次打开弹窗，上传本地图片并保存
- 确认图片仍能更新

预期结果：

- URL 与本地上传两种方式都可用

## 8. 难度兜底逻辑

- 选择某个当前词少或无词的难度
- 点击“卡片学习”或“开始游戏”

预期结果：

- 如果该难度没有默认词库，页面会自动切到同年级有内容的难度
- 会出现提示说明已自动切换

## 9. 回归检查

- 从首页进入卡片学习，再返回首页
- 从首页进入游戏，再进入分析，再返回首页
- 从分析页回首页后再次开始学习

预期结果：

- 页面切换正常
- 不应出现卡死、白屏或按钮失效

## 当前建议重点关注

- 浏览器发音能力依赖系统环境，部分设备可能表现不同
- 外部图片链接和 CDN 资源依赖网络
- 自定义图片与 Excel 导入功能最值得优先实测
