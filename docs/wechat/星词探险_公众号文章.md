# 星词探险：一个给小学孩子用的英语单词学习工具

作者：刘白

最近做了一个给小学孩子用的英语单词学习网页工具，名字叫「星词探险」。

它可以直接在手机浏览器打开，也可以添加到手机主屏幕，像一个小 App 一样使用。

设计目标很简单：让孩子不是只“看过单词”，而是能通过看图、听读、回忆、拼写和阅读，慢慢把单词真正记住。

## 01

## 它是什么

星词探险的首页只有四个主要入口：

- 学新词
- 做挑战
- 读故事
- 看数据

孩子先从「学新词」开始，看图片、听发音、读例句，再进入小挑战。学完以后，可以读一篇由刚学单词组成的小故事。家长也可以在「看数据」里查看学习次数、正确率、错词和复习建议。

目前默认使用六年级基础词库。词库来自小学英语课本词汇整理，尽量使用真实、适合小学阶段的单词数据。

## 02

## 为什么这样设计

背单词不是只盯着英文和中文看。

孩子更容易记住一个词，通常需要多种感官一起参与：眼睛看图，耳朵听音，嘴巴跟读，手指点击或拼写，大脑再把答案想出来。

所以工具里没有把单词做成一张普通词表，而是拆成一条小流程：

先看图理解，再听单词和句子，然后通过看图选英文、听音选英文、英文选中文、看中文拼英文等方式主动回忆。

每次答对，系统会给即时鼓励，也会积累星星。孩子能看见自己的进度，就更容易形成正反馈。

![听读与记忆：听单词、听句子、看有用的记忆提示](video-output/星词探险-demo/frames/03-learn-listen-memory.png)

记忆提示也做了减法。不是每个词都强行拆开记。像 soup、map、taste 这类词，重点是图片、发音、句子和拼写难点；像 weekend、airport、competition 这类词，才适合拆分或音节提示。

也就是说，工具不是给每个词套同一个模板，而是尽量让提示真正对这个词有帮助。

## 03

## 怎么做出来

这个工具是用 AI 编程一点点做出来的。

大致过程是：

1. 先确定学习流程：学新词、做挑战、读故事、看数据。
2. 用 AI 生成网页原型，包括页面、按钮、交互和本地数据结构。
3. 根据真实使用截图反复调整，比如一屏展示、手机适配、按钮大小、阅读页布局、星星进度条。
4. 接入小学词库、图片、发音、例句、导入模板、复习队列和 PWA 离线能力。
5. 最后部署到 GitHub Pages，生成一个可以直接访问的 HTTPS 网页地址。

这个过程不需要一开始就想清楚所有功能。更有效的方式是先做出一个能用的小版本，然后根据孩子使用时遇到的问题继续改。

如果想自己改，可以把项目下载下来，替换词库、图片和例句，再上传到自己的 GitHub Pages。这样同一套工具就可以变成自己的词库版本。

## 04

## 如何试用

项目目前放在 GitHub Pages，可以直接用手机或电脑浏览器打开：

https://vincentliu134-source.github.io/english-word-pwa/enhanced-word-tool.html

iPhone 使用方式：

Safari 打开链接 → 点击分享按钮 → 添加到主屏幕。

Android 使用方式：

Chrome 打开链接 → 点击菜单 → 添加到主屏幕 / 安装应用。

添加到主屏幕后，就可以像普通 App 一样点开使用。
